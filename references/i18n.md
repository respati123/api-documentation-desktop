# Internationalization (Indonesian and English)

Read this before you add or change any text the user sees.

## Setup

- Languages: `id` and `en`. Fallback: `en`.
- Libraries: `i18next`, `react-i18next`, `i18next-browser-languagedetector`.
- Detect the language on first launch. The user changes it from the language switcher. Save the choice in `localStorage` and read it once at startup.

```
shared/i18n/
├── index.ts
└── locales/
    ├── en/common.json, en/<feature>.json
    └── id/common.json, id/<feature>.json
```

One namespace per feature. Shared text goes in `common`.

## Rules

- **No literals.** Every label, title, placeholder, button, empty message, toast, validation message, `aria-label`, `title`, and `alt` comes from a locale file.
- **No keys in views or viewmodels.** They call `t(CONSTANT)`. The constant is an `as const` object in `features/<name>/constants/<name>-text.constants.ts`, or `shared/constants/` for shared text.
- **No literal or template keys.** `t('list.create')` and ``t(`roles.${role}`)`` are not allowed. Use a constant map such as `Record<Role, string>`.
- **Every key in both languages.** Add the constant, then the key in `en`, then in `id`.
- **Keys describe the place**, not the look: `members.empty.title`.
- **Plurals and values** use i18next `count` and `{{name}}`. Never concatenate sentences.
- **Dates and numbers** use `Intl` with the active language, through `@/shared/utils/format-date`.

Enforced by `app/ui-rules.test.ts` (literals and keys) and `bun run i18n-check` (key parity).

## Example

```ts
// features/sync/constants/team-text.constants.ts
export const TEAM_TEXT = {
  members: { removed: 'members.removed', empty: 'members.empty.title' },
  roles: { owner: 'roles.owner', editor: 'roles.editor', viewer: 'roles.viewer' },
} as const

// features/sync/viewmodels/use-team.viewmodel.ts
import { TEAM_TEXT } from '@/features/sync/constants/team-text.constants'

const { t } = useTranslation('sync')
const removedMessage = t(TEAM_TEXT.members.removed, { email })
const roleLabel = t(TEAM_TEXT.roles[member.role])
```

- Views call `t(CONSTANT)` for static labels.
- ViewModels call `t(CONSTANT)` for text that depends on state, and pass the finished string to the View.

## Backend messages

- `apiCall` sends `Accept-Language` with the active language on every request.
- Show the backend `error` text unchanged. Do not translate it by matching its wording.

## Checklist

1. Constant and keys added in `en` and `id`.
2. The screen checked in Indonesian for overflow, since Indonesian text is often longer.
3. `bun run i18n-check` and `bun run test` pass.
